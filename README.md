# 🏨 Hotel Management System

Otel işletmelerinin ön büro, oda ve rezervasyon süreçlerini yönetmek amacıyla geliştirilmekte olan web tabanlı bir otel yönetim sistemi.

## 🚧 Proje Durumu

Bu proje aktif olarak geliştirilmektedir.

Şu anda kullanıcı arayüzü ve temel ön büro yapısı üzerinde çalışılmaktadır. JavaScript ile etkileşimli özellikler aşamalı olarak projeye eklenecektir.

## ✨ Mevcut Özellikler

- Ön büro kontrol paneli
- Oda bilgilerinin görüntülenmesi
- Misafir ve rezervasyon bilgilerinin tablo yapısında gösterilmesi
- Açılır/kapanır yan menü
- Üst navigasyon menüsü
- Menü arama alanı

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript *(geliştirme aşamasında)*

## 🎯 Hedeflenen Özellikler

- Rezervasyon yönetimi
- Misafir yönetimi
- Oda durumlarının dinamik olarak yönetilmesi
- Kullanıcı giriş sistemi
- Backend entegrasyonu
- Veritabanı entegrasyonu
- Raporlama ekranları
